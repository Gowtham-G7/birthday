A LITTLE WORLD JUST FOR YOU — BIRTHDAY WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html (or right-click > Open with > Chrome).
4. Navigate through Surprise → Memories → Love note → Finale.

PERSONALISE IT
Open js/config.js in Notepad or VS Code.
- Change herName to her name or nickname.
- Change letter to your own birthday message.
Save the file and refresh the website.

ADD PHOTOS
Open Memories and click "Add your photos".
You can select up to 12 images. Captions are editable.
Photos and captions are saved in that browser on that device using localStorage.
They are not uploaded to a server. If you share the website ZIP, the recipient will not automatically receive photos saved in your browser; add photos on the device/browser where it will be viewed, or embed images in the project for a shareable hosted version.

PUBLISH / SHARE
To share as a link, upload the extracted folder to a static hosting service such as GitHub Pages or Netlify.
Keep all files and folders together. The site uses Google Fonts when internet is available; it has fallback fonts offline.

FEATURES
- Four linked responsive HTML pages
- Customisable recipient name and letter
- Local photo upload gallery with captions and remove controls
- Animated bear illustration, floating hearts and stars
- Interactive envelope reveal
- Interactive candles, confetti finale
- No backend, login, or database required
